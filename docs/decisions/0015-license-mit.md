# 0015: License: MIT

- **Date:** 2026-10-03
- **Status:** accepted
- **Requirements:** M0-R8, M6-R6

## Context

The design left the license open between MIT and Apache 2.0, to be decided by M6. M0 needs a `LICENSE` file, and contributors should know the terms from their first pull request.

## Decision

The project is licensed under MIT. `LICENSE` names "the project contributors" as the copyright holder, so it doesn't contain the product name and a rename doesn't touch it.

## Consequences

- `docs/design.md` and the README state MIT; the "License" row leaves the open decisions table in `docs/milestones.md`.
- M6-R6 ("License applied") only needs to confirm the file is present in the release.
