# Security and privacy

Glintboard handles what people copy, which can include private information. Please report anything that could expose users' data privately, not in a public issue.

**How to report:** use GitHub's "Report a vulnerability" button on this repository's Security tab (private security advisories). Include steps to reproduce and the version you tested.

**In scope:** data stored or logged when it shouldn't be (for example concealed pasteboard items or private-window URLs), data leaving the device outside the documented opt-in features, permission misuse, and anything that lets captured content trigger actions (prompt injection in AI features).

We aim to acknowledge reports within a week.
